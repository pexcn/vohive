# Country flags

Waved SVG flags from Google Noto Emoji, pinned to revision
`e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e`:

https://github.com/googlefonts/noto-emoji/tree/e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e/third_party/region-flags/waved-svg

Files are renamed from the two regional indicator code points to lowercase
ISO region codes. Artwork is unchanged, including the Taiwan flag (`tw.svg`).
Only two-letter region flags are included; subdivision flags are omitted.
Assets are loaded on demand by `CountryFlag.vue`.

The upstream licensing notice is distributed in
`public/licenses/noto-region-flags.txt`.
